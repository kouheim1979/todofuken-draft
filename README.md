# 都道府県ドラフトバトル — Party Edition

Version **2.0.0-rc.1** / 2026-10-14

47都道府県を指名して、自分だけのチームで対戦するブラウザーゲームです。
既存版の47県・能力値・通常／スネークドラフト・地元ボーナスを継承し、対戦処理とUIを改修しました。

## 遊ぶ

公開先: https://kouheim1979.github.io/todofuken-draft/

「ひとりで遊ぶ」はCPU戦。「みんなで遊ぶ」は1台を交代で使う2〜20人戦です。
人数、1人が指名する県数、地元を設定し、県カードから能力を確認して指名します。
全員が指名したら「作戦会議へ」を押し、プレイヤーごとに並び替えます。
全員の準備が終わると対戦開始。再読み込み後は「続きから遊ぶ」で再開できます。

## 実装済み

- CPU対戦（やさしい／標準）。外部生成AI・API料金・マイクは不要。
- 2〜20人、最大 floor(47 / 人数)県。3／5／10県のプリセット。
- 通常／スネークドラフト、地元+5、全9能力・総合・ランダム勝負。
- ランダム項目を事前公開する作戦モード／非公開モード。
- ひらがな・カタカナ検索、地方フィルター、能力順ソート、47枚のカード図鑑。
- スマホの指ドラッグ／上下ボタン、交代案内、直前指名の取消。
- 明示的なフェーズ移動、二重判定防止、完全同点の同時勝利・同率順位。
- 中断再開、保存破損時の控え、JSONバックアップ、直近20戦、指名県アルバム。
- 効果音ON/OFF、動きを減らす設定、共有失敗時のコピー用表示。
- 招待キー付き共同操作ルームβ。24時間アクセス期限、更新番号の競合検知。

## データについて

**能力値はゲーム用設定です。実統計・住民の能力評価ではありません。**
従来の「人口スコア×14万人」「面積スコア×850km²」「身長スコアからcmを計算」は撤去しました。
地理教材・公的ランキングとして販売できるデータセットではありません。
元の47県の数値とキャッチフレーズは保持しています。

## コードと起動

- `index.html` — 公開版入口
- `data.js` — 47県の原データ
- `engine.js` — DOMや通信から独立した対戦ロジック
- `app.js` / `styles.css` — 画面・入力・保存
- `online.js` / `rooms.sql` — 招待ルームβとRLS
- `sw.js` / `manifest.webmanifest` — オフラインキャッシュ・ホーム画面追加の基盤

依存する外部JavaScriptライブラリーはありません。Google Fontsは任意の装飾で、未接続時は端末フォントで表示します。

開発サーバー:

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。

単一HTML版生成:

```sh
python3 build-standalone.py
```

生成される `todofuken-draft-standalone.html` にCSS・JavaScript・47県データを内包します。
ファイルURLでの保存・共有・オンライン接続にはブラウザーごとの差があります。iPhoneでは公開URLをSafariで開いてください。

## テスト

```sh
node test-engine.cjs
node test-online.cjs
python3 -m pip install playwright==1.57.0
python3 -m playwright install chromium webkit
python3 test-browser.py
```

ブラウザーテストには起動中のHTTPサーバーが必要です。`GAME_BASE_URL` を設定すると公開サイトも検証できます。
`.github/workflows/quality.yml` は通常HTTPでの通し操作と、公開サイトの永続保存・オフライン再読み込みを検証するためのワークフローです。実施済みの記録は `QA.md` を参照。

## 招待ルームβの制限

招待リンクを持つ仲間が共同で操作する仕組みです。プレイヤー別のサーバー強制権限、ランキング不正防止、決済は実装していません。
新しい招待リンクを仲間だけに渡してください。部屋コードだけでは参加できません。
通信エラーや競合は明示し、共有中に勝手にローカル対戦へ移行しません。
旧ROOM-*行は削除していませんが、匿名で全件読み書きできた旧ポリシーを撤去したため、旧コードは新方式に持ち越せません。
期限切れはアクセス拒否であり、保存データの自動削除ではありません。
